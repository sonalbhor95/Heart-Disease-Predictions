# Heart Disease Predictions

This dataset is multivariate, involving multiple mathematical or statistical variables for analysis. It contains 14 key attributes, including age, sex, chest pain type, resting blood pressure, serum cholesterol, fasting blood sugar, resting electrocardiographic results, maximum heart rate achieved, exercise-induced angina, old peak (ST depression caused by exercise relative to rest), the slope of the peak exercise ST segment, the number of major vessels, and Thalassemia.

Although the database includes 76 attributes, most published studies focus on these 14. The Cleveland database is the primary resource used by machine learning researchers. The main objective is to predict whether a patient has heart disease based on their attributes and explore additional insights to better understand the condition.

Column Descriptions:<br>
id: Unique identifier for each patient<br>
age: Patient's age (in years)<br>
origin: Location of the study<br>
sex: Male/Female<br>
cp (chest pain type):<br>
Typical angina<br>
Atypical angina<br>
Non-anginal pain<br>
Asymptomatic<br>
trestbps: Resting blood pressure (in mm Hg on hospital admission)<br>
chol: Serum cholesterol level (in mg/dl)<br>
fbs: Fasting blood sugar > 120 mg/dl (True/False)<br>
restecg: Resting electrocardiographic results<br>
Values: [normal, ST-T abnormality, left ventricular hypertrophy]<br>
thalach: Maximum heart rate achieved<br>
exang: Exercise-induced angina (True/False)<br>
oldpeak: ST depression due to exercise relative to rest<br>
slope: Slope of the peak exercise ST segment<br>
ca: Number of major vessels (0-3) visible via fluoroscopy<br>
thal: Thalassemia [normal, fixed defect, reversible defect]<br>
num: Predicted attribute (heart disease presence)<br>
